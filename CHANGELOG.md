## [1.0.0] - 2026-10-10

- Parse and format Cardano native asset identifiers (policy ID + asset name).
- CIP-14 asset fingerprints with a built-in BLAKE2b implementation.
- CIP-67 labels and CIP-68 reference/user token name helpers.
- Safe display names with strict UTF-8 decoding; zero runtime dependencies.
